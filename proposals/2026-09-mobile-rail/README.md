# S3 Proposal: Mobile Activity Rail Collapse (2026-09)

On mobile, the map's left activity rail is ~12 circular category buttons (~64px each) running the full left edge — roughly 20% of the viewport — which crowds the map, the primary instrument. This mockup compares three ways to reclaim that space in both Day and Night lighting: **(A) Collapse-to-Chip** shrinks the rail to one 40px pill showing the active filter (icon + label + count badge) and opens a compact 4-column grid in a bottom sheet; **(B) Compact Rail** keeps the vertical rail but halves the footprint with 40px circles, 8px gaps and count badges, with the active state as a tonal chip plus inset gold ring (a beam, never a gold fill); **(C) Horizontal Strip** replaces the rail with a single labeled, horizontally scrollable strip pinned above the bottom-sheet area.

**Recommendation: Variant A (Collapse-to-Chip)**, with B's inset-gold-ring active treatment borrowed for the sheet cells. The chip gives the smallest resting footprint while still keeping the active filter readable as an instrument reading (icon + label + count, never color alone); the bottom sheet is the established mobile pattern and has room for the occupancy filter that the current rail also carries. Variant B is the fastest for repeated filter toggling but degrades back toward the original problem as categories grow, and Variant C costs the most vertical space exactly where the bottom sheet lives and puts its buttons in the worst thumb zone.
